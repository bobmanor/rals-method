# First Release Checklist

- [ ] Bob Manor reviews the method language and source history.
- [ ] The rights holder and license are approved in `LICENSE-DECISION.md`.
- [ ] The official full license text is added as `LICENSE` or `LICENSE.md`.
- [ ] The README license section is updated.
- [ ] `OWNER/REPOSITORY` is replaced with the real GitHub path.
- [ ] The trademark notice is reviewed for the intended ownership and marks.
- [ ] All five public URLs open and their titles and dates are checked.
- [ ] No private, client-identifying, or unverified material is included.
- [ ] Markdown links work in GitHub preview.
- [ ] A first release is tagged after publication.
