# License Decision Required Before Open Release

## Current status

No content license has been approved for this repository. Until a license is selected and its full text is added, copyright law reserves reuse rights by default. The repository may be uploaded for review, but it should not be described as open source or openly licensed yet.

This is a decision for Bob Manor or the verified rights holder. It is not a decision an AI assistant should make on the owner's behalf.

## Recommended default

**Creative Commons Attribution 4.0 International (CC BY 4.0)** is the leading option for the repository's written documentation, examples, and prompts if the goal is broad use and adaptation with required attribution, including commercial use.

Why it fits:

- It is designed for creative and documentation content rather than software code.
- It permits sharing and adaptation.
- It requires appropriate credit, a license link, and indication of changes.
- It can coexist with a separate trademark notice.

Tradeoff: it permits commercial reuse and adaptations, including versions the creator may dislike, provided users comply with the license and do not misuse the trademark or imply endorsement.

## Other options

### CC BY-SA 4.0

Requires adaptations to use the same license. This supports an open commons but can complicate reuse in materials with incompatible licensing.

### CC BY-NC 4.0

Restricts commercial use. This may feel protective, but “NonCommercial” can create uncertainty for consultants, publishers, training teams, and companies. It is not generally treated as an open-source or open-culture license.

### All rights reserved with a custom permission statement

Allows tighter control but is not open source. Custom licensing adds ambiguity and legal drafting cost.

### Software licenses such as MIT or Apache 2.0

These are familiar on GitHub but are not the clearest fit for a repository made primarily of prose, examples, and prompts. If software is later added, that code can use a separate software license.

## Approval checklist

Before publishing the repository as open:

1. Confirm the copyright owner.
2. Choose the license.
3. Add the official, unmodified license text as `LICENSE` or `LICENSE.md`.
4. Update README's license section.
5. Retain the separate trademark notice.
6. Confirm that every included contribution and asset can be released under that license.
7. Consider legal review if commercial training, certification, or brand licensing is planned.

## If CC BY 4.0 is approved

Use the official license text from https://creativecommons.org/licenses/by/4.0/legalcode and add this plain-language notice to the README:

> Except where otherwise noted, the written content in this repository is licensed under the Creative Commons Attribution 4.0 International License. RALS Method™ and related brand identifiers are not licensed for use as trademarks. See ATTRIBUTION-AND-TRADEMARK.md.

Do not paste only the summary notice in place of the full legal text.
